# DESIGN DIRECTION (from founder inspiration)

Reference: `assets/inspiration/inspo-01.jpg` ("Estilos Tipográficos" poster).
This is the look we are matching. Recreate the *system*, not the exact image.

## The aesthetic (editorial poster / YouTube-thumbnail energy)
- **Giant condensed bold display type BEHIND the subject** — the niche/topic word,
  in brand yellow `#ffbe00`, oversized, slightly cropped by the canvas edges.
- **Script/serif accent word** overlapping the big type (a smaller emotive word).
- **Subject cut-out in FRONT**, overlapping and partly occluding the big type
  (this is the "person in front, logo/type behind" rule).
- **Technical corner metadata** — current year, short ALL-CAPS labels
  (e.g. "TOP 10", "DIFFERENCE"), a thin **vertical ruler scale**, small geometric
  logo marks. Monospace/condensed, muted.
- **Background**: muted grey→dark gradient (our `#121212` base, keep premium grade).
- **One accent color only**: yellow. Everything else fg/muted/green per brand.
- **Bottom 30% black gradient band** holds the readable Q&A/difference text
  (this is on top of the poster layout — locked rule from CONTENT_METHOD.md).

## How it maps to the 4-slide post
- Slides 1-3: this poster system per subject — big yellow topic type behind,
  subject photo in front, corner metadata + ruler, bottom-30% text band with the
  hook/question → difference → number. Bee.png + hanubees.com watermark.
- Slide 4: the fixed agency card (bigger bee).

## Layering order (back → front)
bg gradient → giant yellow display type → subject brand logo (bg-removed) →
subject cut-out photo → script accent word (optional, can sit behind subject) →
corner metadata + ruler + geo marks → bottom-30% black gradient → text → watermarks.
