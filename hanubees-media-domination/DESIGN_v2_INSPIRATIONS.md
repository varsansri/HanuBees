## Inspiration #1 — `assets/inspiration/inspo-02-editorial-halftone.jpg`
Style name: **editorial-halftone** (zine / typographic poster, @justshikoo).
WHY IT FITS US: 100% buildable in code — the "photo" is a 1-bit HALFTONE/DITHER duotone,
not real media. Everything here is type + shapes + dot patterns. No alignment risk.

### Extracted tokens (reproducible)
- **Canvas:** square here, but our spec is 3:4 — adapt the same system vertically.
- **Palette:** off-white paper `#f2f0eb`-ish bg · near-black navy `#11163a` ink ·
  ONE hot accent (magenta/red `#ff1f5a`). For US: swap accent to brand yellow `#ffbe00`,
  keep off-white + near-black. One accent only (brand rule).
- **Hero headline:** GIANT bold display, edge-to-edge, near-black (e.g. "Something Weird").
  This is where our PUNCHY math/dating HOOK goes.
- **Top metadata bar:** tiny labels — `instagram / @handle` (left), Japanese gloss +
  `©2026` (right). Thin full-width hairline rule under it.
- **Label strip:** a row of small captions ("some info", JP text, "typography.") on a
  hairline-divided row. We repurpose as: `GIVEN · FORMULA · SOLVE · ANSWER` mini-labels.
- **Focal block:** magenta rectangle holding a HALFTONE-dithered subject. For us this is
  where the "woman" hook visual lives — generated as a halftone illustration/shape, OR
  replaced by a big FORMULA rendered as the focal art. (Stay text/shape-built; no photos.)
- **Bottom-right:** real-looking BARCODE + micro caption ("08/06 / made with love").
  We reuse barcode + a code line (date / post-id) as the "technical" garnish.
- **Texture:** subtle halftone dot grid; thin technical hairlines; monospace micro-labels.
- **Font feel:** tight grotesque/Helvetica-Neue display. Our brand display = MADE Okine
  Sans (already in config). Keep micro-labels in a mono.

### How it maps to our worked-problem post
- Headline band = the HOOK question ("50 approaches. 0 girlfriends.").
- Label strip = QUESTION→GIVEN→FORMULA→SOLVE→ANSWER stages.
- Focal block = the FORMULA itself set big as the art (G = R × c1·c2·c3·c4), halftone bg.
- Footer = barcode + ©2026 + hanubees.com + bee logo.
