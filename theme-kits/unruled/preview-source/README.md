# Unruled preview source

This is the standalone source behind the live Unruled browser preview.

## Run locally

1. Install Node.js 20 or later.
2. Run npm install.
3. Run npm run dev.
4. Open http://localhost:3000.

Product, search, newsletter, and cart behavior are demonstration interfaces.
Connect them to your commerce and customer services before production use.

The source screenshot used for visual composition is not included. Every image
inside public/themes/unruled was created for this Hanubees release.
