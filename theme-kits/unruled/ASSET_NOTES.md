# Asset notes

The seven images shipped with Unruled were generated specifically for this
Hanubees theme build. They contain fictional models, original garment artwork,
and no intended third-party marks.

The user-supplied source screenshot is a composition reference only and is not
included in either download.

Before using any generated person or garment artwork in a public commercial
campaign, perform the same legal, cultural, and brand review you would apply to
commissioned photography. Replace these demo assets if your organization has
specific model-release or provenance requirements.
