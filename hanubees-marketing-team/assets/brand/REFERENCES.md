## Visual-effect libraries (for the WEBSITE / animated visuals — browser/WebGL only)
> These render live in React/WebGL; they can't export static images. Use them on the
> site (hero, animated logo, glass UI). For IG/TikTok image cards we recreate the look with SVG.
- ShaderGradient — animated gradient backgrounds → https://github.com/ruucm/shadergradient
- liquid-logo — liquid/metaball logo effect → https://github.com/paper-design/liquid-logo
- liquid-glass-js — Apple-style liquid glass → https://github.com/dashersw/liquid-glass-js
- react-three-fiber — React renderer for three.js (3D) → https://github.com/pmndrs/react-three-fiber
